# Achados Inteligentes — Gerador automático de vídeos

Projeto experimental gratuito para gerar vídeos verticais MP4 para a página Achados Inteligentes, sem edição manual.

## Objetivo da V1
- Gerar vídeo vertical 9:16 de aproximadamente 15 segundos.
- Produzir fundo animado, cartões e legendas automaticamente.
- Gerar narração em português com a voz disponível no Windows, sem APIs pagas.
- Exportar um único arquivo MP4.

## Limitações
Esta primeira versão gera **animações programáticas**, não filmagens realistas como as criadas pelo Kling. Vozes do Windows podem soar artificiais; a qualidade depende das vozes instaladas. O conteúdo e as licenças devem ser revisados antes de publicar propaganda.

**Nenhuma chave de API, senha ou token deve ser colocada neste repositório.**
